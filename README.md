# Print Guide

Адаптивная верстка Figma-макета «Гайд — печатка». В проекте есть главная страница, главы «База» и «Полиграфия», светлая и тёмная темы, поиск, интерактивные чек-листы, копирование примеров и мобильная навигация.

## Запуск

```bash
npm start
```

После запуска откройте [http://localhost:4173](http://localhost:4173).

Проект не требует установки зависимостей.

## Где редактировать содержимое

- Главная страница: `index.html`
- Глава 1 «База знаний»: `chapters/chapter-1/index.html`
- Глава 2 «Полиграфия»: `chapters/chapter-2/index.html`
- Общие стили: `styles.css`
- Интерактивность и состояние чек-листов: `app.js`

Файл `bootstrap.js` автоматически подгружает главы в общую оболочку сайта. Открывайте проект через локальный сервер (`npm start`), а не двойным кликом по `index.html`.
